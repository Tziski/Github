# Tagwerk

Ein einfacher Tagesplaner für Gewohnheiten: täglich abhaken, die Woche im Blick behalten und Serien aufbauen.

## Ausprobieren

`index.html` im Browser öffnen. Die Daten werden lokal im Browser gespeichert (localStorage).

## Aktueller Stand

- Tagesübersicht mit Datum und Fortschrittsbalken
- Gewohnheiten anlegen, bearbeiten und löschen
- Wochenpunkte (Mo bis So), auch für vergangene Tage nachtragbar
- Serien-Zähler (Tage bei täglichen Gewohnheiten, Wochen bei Wochenzielen)

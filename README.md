# Tagwerk

Ein Tagesplaner für Gewohnheiten. Jede erledigte Gewohnheit bewegt die Sonne ein Stück weiter über den Tagesbogen. Wenn alles geschafft ist, geht sie unter.

## Ausprobieren

`index.html` im Browser öffnen. Die Daten bleiben lokal im Browser gespeichert.

## Funktionen

- Gewohnheiten abhaken, anlegen, bearbeiten und löschen
- Ziel pro Woche (1 bis 7 Tage)
- Wochenbalken zum Nachtragen vergessener Tage
- Serien in Tagen oder Wochen
- Heller und dunkler Modus
